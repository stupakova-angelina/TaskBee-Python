# 🐝 BeeDo — Умный список дел на Python

Простое приложение для управления задачами с графическим интерфейсом. Создано для участия в конкурсе **«Талант НТО»**.

## 🖼️ Как это выглядит
![Интерфейс BeeDo](screenshots/demo.png)

## 🚀 Возможности
- Добавлять задачи
- Отмечать как выполненные
- Удалять задачи
- Сохранять данные между сессиями
- Загружать задачи из файла
